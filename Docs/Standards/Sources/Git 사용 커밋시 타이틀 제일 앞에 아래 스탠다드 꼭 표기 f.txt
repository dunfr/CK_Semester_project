Git 사용 커밋시 타이틀 제일 앞에 아래 스탠다드 꼭 표기 feat, fix, docs, style, refactor, test, chore  feat : 기능추가 fix : 내용 수정 docs : 문서 내용 수정 style : 코드/기능에 영향 안주는 변경 refactor  : 리팩토링 test : 테스트용 ~ 씬 만들어 테스트/ 로그 찍어 테스트 등 chore : 빌드, 설정 파일, 패키지 매니저 설정 등 외적인 부분을 변경  예시 :  feat : 플래시 기능 추가  fix : 셰이더 그래프 변경   style : 프리팹 모델링 변경  refactor : 기존 맵 생성 시스템 리팩토링   test : 스트레스 테스트 - 광원 1만 배치   chore : 프로젝트 세팅 씬 세팅 변경
