# 레벨 디자인 프리셋 (적 이동 · 컷씬)

코드 수정 없이 씬에서 배치·설정하는 프리셋 2종입니다.
만들기: Hierarchy 우클릭(또는 상단 GameObject 메뉴) > **CK Level Presets**

- 코드: `Assets/CK_Semester_Project/Prototype/Scripts/LevelDesign/Presets/`
- 에디터(인스펙터·메뉴·씬 표시): `Assets/CK_Semester_Project/Editor/LevelDesignPresets/`
- 적 배치 도구: 상단 메뉴 **CK > 적 배치 도구** (또는 CK Level Presets > 적 생성)

## 0. 적 배치 도구 (EnemyPlacementWindow)

맵의 적은 이 도구로 만듭니다. 기본 적 프리팹: `Prefabs/Characters/FieldEnemy.prefab`

1. 몬스터 종류(MonsterBattleDefinition)와 넣을 위치(예: 구역의 `Enemies`)를 고릅니다.
2. 행동: 제자리 감시 / 웨이포인트 순찰(적 이동 프리셋 자동 생성, 트리거 반응 포함 선택) / 주변 무작위 순찰
3. **씬 뷰 클릭으로 배치**를 켜고 바닥을 클릭(Esc로 종료)하거나 **씬 뷰 중앙에 생성**.
4. 자동 연결: 플레이어 감지 대상, 전투 대상 목록(선택), 튜토리얼 경비병(선택, 01 구역 시작 연출)
5. 아래 '씬의 적' 목록에서 선택·삭제. 삭제하면 전투 목록과 그 적의 이동 프리셋도 함께 정리됩니다.

- 튜토리얼 경비병이 없으면 시작 연출 뒤 바로 카드 키가 올라옵니다.
- 덕트 소리·붕괴 이벤트에 반응할 적은 각 이벤트(DuctNoiseEvent, DuctCollapse) 인스펙터 목록에 직접 넣습니다.

## 1. 적 이동 프리셋 (EnemyRoutePreset)

적을 선택한 채로 메뉴 **적 이동 프리셋**을 실행하면 그 적에 연결된 프리셋이 생깁니다.

| 항목 | 설정 방법 |
| --- | --- |
| 웨이포인트 위치·순서 | `Waypoints` 아래 자식(WP_01, WP_02…)을 옮깁니다. 하이어라키 위→아래 순서가 순찰 순서. 인스펙터 **웨이포인트 추가** 버튼 |
| 순찰 방식 | 반복(1→2→3→1) / 왕복(1→2→3→2→1) |
| 이동 속도 | 순찰 이동 속도, 반응 이동 속도 (m/s) |
| 웨이포인트 대기 | 각 지점에서 멈추는 시간(초) |
| 트리거 영역 위치·크기 | `Trigger` 오브젝트 위치와 BoxCollider Size |
| 반응 시 이동 | 지점으로(`ReactionPoint`) / 방향으로(방향 벡터 + 거리) / 플레이어 쪽으로 |
| 도착 후 바라볼 곳 | 선택. 비우면 이동 방향 |
| 복귀 시점 | 도착 후 대기 시간이 지나면 / 플레이어가 영역을 나간 뒤 대기 시간이 지나면 |
| 발동 조건 | 1회만, 재발동 쉬는 시간, 추적 중이면 무시 |

- 복귀하면 원래 순찰 경로의 다음 웨이포인트부터 이어서 돕니다.
- 적에게 기존 AI(EnemyStateMachine)가 있으면 순찰 중 시야 감지·소리 반응·추적은 그대로 동작합니다. 반응 이동 동안에는 감지가 잠시 꺼집니다.
- 웨이포인트를 받은 적은 '제자리 감시' 설정이 꺼지고 순찰합니다.
- 씬 뷰: 하늘색 화살표 = 순찰 경로(번호 표시), 빨간 화살표 = 반응 이동, 주황 박스 = 트리거 영역.

## 2. 컷씬 프리셋 (CutscenePreset)

씬 뷰를 원하는 장소·구도로 맞춘 뒤 메뉴 **컷씬 프리셋**을 실행하면 트리거·카메라 샷·도착 지점과 기본 단계 3개(카메라, 대사, 이동)가 만들어집니다.

| 항목 | 설정 방법 |
| --- | --- |
| 트리거 | `Trigger` 위치와 BoxCollider Size |
| 1회만 재생 | 체크 |
| 플레이어 조작 잠금 | 체크 |
| 단계 순서 | 인스펙터 단계 목록에서 끌어서 변경. **+ 대사 / + 이동 / + 카메라 / + 대기** |
| 타이밍 | 단계마다 '앞 단계가 끝난 뒤 / 앞 단계와 동시에' + 시작 전 대기(초) |
| 대사 | 말하는 캐릭터, 대사, 표시 시간(0이면 F·Space·Enter로 넘김) |
| 이동 | 캐릭터(비우면 플레이어), 도착 지점, 속도, 도착 방향으로 회전 |
| 카메라 | 샷(위치·각도) 여러 개 = 경로, 샷 사이 이동 시간, 마지막 샷 유지 시간, 계속 바라볼 대상 |

- 카메라 단계를 선택하고 **지금 씬 뷰 시점으로 샷 추가**를 누르면 씬 뷰 구도가 그대로 샷이 됩니다. 샷은 `Shots` 아래 오브젝트라 직접 옮겨도 됩니다.
- 이동 단계를 선택하고 **도착 지점 만들기**를 누르면 `MovePoints` 아래 지점이 생깁니다. 지점의 파란 축(앞)이 도착 후 바라볼 방향입니다.
- 카메라는 컷씬이 끝날 때까지 마지막 샷에 머물고, 끝나면 플레이 카메라로 돌아갑니다.
- 전투 중에는 시작하지 않습니다. 시작·종료 시 이벤트(UnityEvent)로 문 열기 등 다른 동작을 연결할 수 있습니다.
