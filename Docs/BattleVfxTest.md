# 이펙트 제작 테스트 씬

`Assets/CK_Semester_Project/Prototype/Scenes/BattleVfxTest.unity`를 열어 사용한다.
이 씬은 더미를 기준으로 이펙트를 배치·편집·저장하고 미리 보는 작업장이다. 저장·덮어쓰기·삭제는 전투 데이터와 독립적으로 동작한다.

## 씬에서 편집하고 저장하기

1. Project의 이펙트 프리팹을 씬에 끌어다 놓는다.
2. 루트에서 `Add Component > CK > 이펙트 배치 저장`을 추가한다.
3. 루트의 위치·회전·크기를 조절하고 자식의 Transform, Particle System, 컴포넌트, 활성 상태를 평소처럼 수정한다.
4. `새 저장 이름`을 입력하고 `다른 이름으로 저장 (기본)`을 누른다. 매번 새 복사본을 만들며 같은 이름은 `(2)`, `(3)`처럼 번호를 붙인다.
5. 기존 저장본을 바꾸려면 `덮어쓸 저장본`에서 대상을 선택하고 `선택한 저장본 덮어쓰기…`를 누른다. 확인 창에서 승인해야 저장한다. 선택한 저장본의 이름·경로·GUID는 유지하며, 취소하면 변경하지 않는다.

기준 더미 `VFX Training Dummy`와 이펙트 루트는 자동으로 찾는다. 루트에는 더미 기준 상대 위치·회전을 저장하며, 세 축 크기와 자식 수정값은 복사본에 보존한다. 컴포넌트를 자식에 추가해도 해당 프리팹 루트를 저장한다.

원본 프리팹은 유지한다. 공유 머티리얼·텍스처 에셋을 직접 수정하면 Unity의 일반 동작대로 다른 사용자에게도 반영된다. 작업용 원본은 Play 중 숨겨지며, 저장본은 아래 관리 Inspector에서 확인한다.

## 저장 목록과 미리보기

1. Hierarchy의 `BattleVfxSavedEffects` 컴포넌트가 있는 관리 오브젝트를 선택한다. 기본 생성 이름은 `저장된 이펙트 관리`이며 이름을 바꿔도 동작한다.
2. `이름 검색`에 이름 일부를 입력해 찾는다. 대소문자를 구분하지 않으며 `초기화`로 전체 목록을 다시 볼 수 있다. 한 페이지에는 최대 8개를 표시하며 `이전`·`다음` 또는 목록에 포커스가 있을 때 PageUp·PageDown으로 이동한다.
3. 이름으로 표시된 목록에서 저장본을 선택하고 `재생 / 처음부터`를 누른다. Play 없이 기본 더미를 기준으로 저장한 배치를 재생하며 Scene 뷰도 해당 위치로 맞춘다.
4. `일시정지 / 계속`, `정지`, `반복 재생`, `미리보기 속도`, `재생 위치 (초)`로 확인한다. 시간 슬라이더를 움직이면 일시정지한다.
5. `선택한 저장본 삭제`를 누르고 확인하면 해당 저장본만 휴지통으로 옮긴다. 다른 저장본과 원본 프리팹은 유지한다.

새 저장본은 목록에 자동 반영된다. 필요하면 `목록 새로고침`을 누른다. 기본 저장은 새 복사본을 만들므로 이전 버전도 목록에서 비교·재생할 수 있다.

파티클과 베기 메시·타격선은 같은 시간축에서 반복한다. 미리보기 속도는 저장된 파티클 설정을 바꾸지 않는다. 미리보기 복제본은 씬에 저장되지 않으며 선택 변경·Play 전환·씬 닫기·재컴파일 시 정리한다. 재생과 삭제는 Edit 모드에서 사용한다.

## 이펙트가 주변을 비추는 조명

벚꽃 이펙트 프리팹의 `이펙트 조명` 자식에서 Light의 Color·Intensity·Range로 빛의 색·최대 밝기·영향 범위를 조절한다. `Effect Light Pulse` 컴포넌트의 Duration은 초 단위이며 Intensity Curve는 재생 시간 0~1에 따른 밝기 배율이다. 이펙트 표면은 기존 Unlit 셰이더를 유지한다.

자식 Light와 조명 재생 컴포넌트도 배치 저장에 포함된다. 저장 목록 미리보기의 시작 지연·반복·속도·재생 위치에 조명이 함께 맞춰지며, 종료 구간에는 빛이 꺼진다. 직접 생성한 프리팹은 활성화 시 조명이 한 번 재생된다. 차징 이펙트는 기존 Particle System의 Lights 모듈을 사용한다. 캐릭터 툰 셰이더도 추가 광원을 받아 조명 색이 반영된다.

## 저장 위치와 배치 기준

- 저장본: `Assets/CK_Semester_Project/Prototype/Prefabs/BattleVfxTest/Saved/`
- 새 파일명: `Vfx_<고유 GUID>.prefab`
- 저장된 이름·더미 상대 배치·재생 메타데이터: 해당 프리팹의 importer userData
- 기본 더미 능력치 에셋: `Prototype/Data/BattleVfxTest/VfxTrainingDummy.asset`

위치 단위는 더미 크기에 영향을 받지 않는 미터다. 더미를 이동하거나 회전해도 같은 상대 배치로 재생한다. Missing Script, 이펙트 밖의 씬 오브젝트 참조, 비균일 부모로 인한 전단 변형은 저장 전에 안내한다. 전단 변형은 루트를 Hierarchy 최상위로 옮겨 해결한다.

테스트 씬은 자동 전투를 시작하지 않으며 더미 AI와 이동을 정지한다. 화면의 안내 자막과 재시작 버튼은 제거했으며, F5로 캐릭터·더미 위치를 복구할 수 있다. 기존 수치 배치 창은 관리 오브젝트를 선택하는 바로가기로 정리했다.

## 검증 (2026-10-21)

- 독립 저장·목록·삭제·상대 배치·재생 테스트 21개가 통과했다. 사용하지 않는 이전 편집 계층과 전용 테스트는 제거했다.
- 안내·재시작 UI가 없는 실제 작업장 PlayMode 테스트 2개가 통과했다. 화면 UI 제거 후에도 F5 위치 초기화와 저장 목록 오브젝트는 유지된다.
- 저장·덮어쓰기·목록 조회·삭제 전후에 전투 설정 에셋의 메모리 값과 파일 바이트가 같은지 확인했다.
- 기존 저장본 두 개는 이름·GUID·배치를 유지하고 파일명만 독립 형식으로 정리했다. 씬에 편집 중이던 이펙트의 루트·자식 Transform 36개와 관리 오브젝트 이름도 보존했다.
