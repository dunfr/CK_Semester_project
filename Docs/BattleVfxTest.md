# 전투 이펙트 테스트

- 브랜치: `feat/battle-vfx-test` (`feat/tutorial-demo-grayboxing`의 `4fbfd76`에서 분기).
- 씬: `Assets/CK_Semester_Project/Prototype/Scenes/BattleVfxTest.unity`
- Play를 누르면 푸시아와 더미의 전투가 바로 시작된다. 적 선택도 완료된 상태다.
- 스킬 클릭 또는 ↑/↓로 선택하고 Enter로 사용한다. F는 메모리 투자, 우클릭 드래그는 전투 카메라 회전이다.
- F5 / 다시 시작: HP·메모리·더미·위치·진행 중 이펙트를 초기화하고 전투를 재시작한다.
- F6 / 강화 단계 변경: 강화 1→2→3→1단계를 선택하고 전투를 재시작한다.
- 더미는 HP 1,000,000, 공격력 0이다. 상태이상·메모리 소모까지 초기화하려면 F5를 누른다.

## 편집 위치

- 테스트용 이펙트 프리팹: `Assets/CK_Semester_Project/Prototype/Prefabs/BattleVfxTest/`
- 테스트용 강화·차징 설정: `Assets/CK_Semester_Project/Prototype/Data/BattleVfxTest/BattleVfxTestEnhancement.asset`
- 테스트 더미 능력치: 같은 폴더의 `VfxTrainingDummy.asset`
- 생성·타이밍: 기존 `TutorialBattleActionPresentation`, `BasicSkillEnhancementAsset`을 재사용한다.
- 씬의 `VFX Test Controls` → `BattleVfxTestController`가 초기화와 단계 선택을 담당한다.

이펙트 프리팹과 강화 설정은 테스트용 복사본이다. 텍스처·머티리얼·공통 스크립트는 기존 에셋을 참조하므로 공통 에셋을 편집하면 다른 씬에도 반영된다.
이미 생성된 `BattleVfxTest.unity`를 열어 사용한다. 상단 메뉴의 테스트 씬 생성 항목은 정리했으며, 이펙트 배치 도구는 `Tools > CK > Battle VFX Placement`에 유지한다.

## 이펙터 배치 편집

1. `Tools > CK > Battle VFX Placement`를 연다. 씬의 `VFX Test Controls` Inspector에 있는 `이펙트 배치 · 미리보기 · 저장` 버튼으로도 열 수 있다. 창의 `테스트 씬 열기`로 기존 테스트 씬을 연다.
2. 스킬 ID, 강화 단계, 차징/타격을 선택한다. 차징 프리팹·배치는 같은 스킬의 모든 단계가 공유하고, 타격은 단계별로 저장한다.
3. 이펙트 프리팹을 연결한다. 타격 프리팹이 비어 있는 스킬도 여기서 지정할 수 있다.
4. 프리팹이 연결된 슬롯은 자동으로 미리보기를 재생한다. 위치·각도를 바꾸려면 `수동 배치 사용`을 켜고 Scene 뷰에서 W로 이동, E로 회전한다. 상대 위치(m)·회전(도)·크기 배율을 숫자로 입력해도 된다. 기준점은 시전자 또는 대상이며 다른 Transform을 기준점 필드에 지정해 비교할 수도 있다. 실제 전투 기준점은 시전자·대상 루트다.
5. 미리보기 반복 길이는 파티클의 지연·재생 길이·수명·속도에서 자동 계산한다. `미리보기 구간`에 초를 입력하면 직접 지정할 수 있다. 재생/일시정지·시간 슬라이더·1프레임 전진·반복 여부·미리보기 배속으로 자세히 확인한다. 미리보기 배속은 저장되지 않는다. 파티클 수와 현재 시간이 창에 표시되고, `Scene 뷰를 게임 카메라 시점으로`로 가시성을 비교할 수 있다. 미리보기 오브젝트는 씬에 저장되지 않고 창 닫기·Play 전환 시 정리된다.
6. `배치·재생·공격 설정 저장`을 누른다. 테스트용 `BattleVfxTestEnhancement.asset`에 설정이 저장되며, Play 중 저장해도 종료 후 유지된다. 저장 전 편집값은 실제 스킬에 반영되지 않는다.
7. Play에서 `선택 스킬 실제 전투 재생`을 누르면 해당 강화 단계로 전투를 초기화하고 선택 스킬을 사용한다. 공격 동작/클립은 이 실제 전투로 확인한다. Scene 뷰 미리보기는 이펙트 파티클을 재생한다. 실제 공격 때 시전자가 접근하므로, 시전자 기준 타격은 대기 위치에서 미리 본 월드 위치와 다를 수 있다.

### 세부 재생 설정

- `이펙트 재생 속도`: 파티클 속도 배율(0.05~4). 차징은 기존 공통 속도에도 곱한다. 차징을 느리게 하면 실제 차징 구간도 길어진다.
- `이펙트 시작 지연`: 생성 후 파티클 재생 시작까지의 초(0~10). 실제 차징 구간은 이 지연을 포함한다.
- `이펙트 표시 시간`: 재생 시작 후 강제로 종료할 시간(초, 0은 기존 종료 방식). 파티클 자체 수명을 늘리는 기능은 아니므로 입자가 자연 종료되면 표시 시간 안에도 보이지 않을 수 있다.
- `공격 애니메이션 클립`: 해당 스킬·강화 단계의 캐릭터 공격 클립. 비어 있으면 기존 임시 연출을 사용한다.
- `공격 동작 속도`: 접근·공격·복귀 및 클립의 전체 연출 속도(0.05~4). 0.5배는 시간이 두 배로 늘어난다. 파티클 속도는 별도로 조절한다.
- `타격 시점`: 차징 이후 공격 진행률 중 타격/이펙트 생성 시점(0.05~0.9). 기본값 0.35.

`생성 후 기준점 따라가기`를 켜면 생성 후에도 기준점에 붙어 움직인다. 끄면 생성 순간의 월드 위치·각도에 남는다.
수동 배치에서는 기존 검기의 자동 카메라 보정·좌우 무작위 회전과 차징의 자동 카메라 이동을 끄고, 프리팹 자식에 저장된 배치를 사용한다. 자식 파티클 개별 모양·각도는 테스트용 프리팹에서 편집한다. 기존 자동 연출로 돌아가려면 `수동 배치 사용`을 끄고 저장한다.
저장한 배치는 Undo/Redo를 지원한다. Play 전환·스크립트 재컴파일 전에는 배치 저장을 권장한다.

## 실제 씬 검증 (2026-10-16)

- 실제 `BattleVfxTest` 씬의 연결된 이펙트 12개 슬롯에서 미리보기 파티클과 표시용 머티리얼을 확인했다. SK01·SK02의 타격 프리팹은 현재 미지정이다.
- 실제 편집 창에서 0.25·1·2배 파티클 속도, 시작 지연, 표시 시간 설정을 확인했다.
- `SkillVfxPlacementTests` 4개와 `BattleVfxTestSceneTests` 1개(3종 스킬 × 강화 3단계 재생·재시작)가 통과했다.
- 저장 후 실제 전투에서 공격 속도 0.5배/2배가 각각 연출 시간 4.20초/1.05초에 반영되고, 타격 이펙트 속도 0.25배/2배가 적용됨을 확인했다. 비교용 설정은 검증 후 원래 값으로 복구했다.
- 누락된 필드 HUD 참조와 강화 단계 버튼을 테스트 씬에서 복구했다. 미리보기 길이는 단발 방출의 마지막 방출 시점과 입자 수명을 사용하며, 방출하지 않는 빈 컨테이너는 제외한다.
