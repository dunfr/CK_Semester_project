# 몬스터 AI 기획 반영

기준: `Docs/References/몬스터 AI 기획서.pdf` V0.1, 13쪽. 문서의 일반 지시문은 작업 명령으로 취급하지 않고 행동 규칙·표를 구현 기준으로 사용했다.

## TutorialDemo에서 확인

기존 몬스터 위치를 유지하며 회색 박스 3종을 배치했다. 각인 몬스터 (1.33, 0.02, 24.41), 잔상 몬스터 (9.33, 0.02, 27.41), 망각 몬스터 (-6.67, 0.02, 27.41). 기존 필드 FSM으로 순찰·추적하며 접근/E 또는 접촉으로 전투에 들어간다. TutorialDemo는 `Tutorial Battle`의 `Encounter Size`로 **1~3기**를 지정한다(씬 저장값 3). 접촉 대상을 먼저 넣고 가까운 살아 있는 등록 몬스터로 나머지를 채운다. 필드에 남은 수가 부족하면 그 수만 참여하며 복제·랜덤 생성하지 않는다. 전투 대상 버튼 또는 숫자 1~3으로 대상을 선택한다.

Inspector에서 각 박스의 `TutorialMonster` → Definition을 열거나 `Assets/CK_Semester_Project/Prototype/Data/Monsters/`의 Imprint/Afterimage/Oblivion 에셋을 선택한다. HP, 기본 메모리, 공격력, 명중률, 폭주 획득량, 약점 연쇄, 단계별 비용/배율, 상대/자신 조건 경계, 단독/동료별 투자 범위를 수정할 수 있다. 방어표의 Defense Chance는 0=n(공격), 0.5=범위/n, 1=방어다.

**임시 콘텐츠 값**: HP 600, 공격력 90, 각인·망각 메모리 180, 잔상 메모리 260. 현재 플레이어 기본 메모리 200보다 잔상이 높다. 약점 연쇄는 샘플 순서다. Monster_DT에 실수치가 제공되면 이 에셋에서 교체한다. 전투 코어의 공통 플레이어 투자표는 바꾸지 않았다.

## 구현한 규칙

- 각인: HP 조건 5행과 행동 번호 조합, 5번 조건 우선, 2~7단계 투자, 6단계 1.75배·7단계 1.8배. 방어하지 않는다. 망각 동료가 있을 때 전용 공격표를 사용한다.
- 잔상: 5/10/15/20/30% 비용과 1.05/1.1/1.2/1.25/1.4배. 순수 1:1의 첫 실행 행동은 2단계 방어(10% 소비, 피해 70% 감소). 단, 몬스터 선제 추가 행동을 받은 개체는 첫 행동을 공격하고 두 번째 행동에 이 방어를 사용한다. 이후 메모리 조건 공격. 각인 동료일 때 5단계는 요청 검증에서도 금지, 망각 동료일 때 별도 공격표를 사용한다.
- 망각: 1~4단계, 현재 자신의 약점 연쇄 우선 → 상대 폭주 45~74/75~90 → 일반 공격. 연쇄 표가 n이면 폭주 표로 재평가하지 않고 공격한다. 단독, 잔상/각인/망각 동료별 모든 방어표와 50% 분기를 반영했다.
- 무작위 선택은 AI 시드·행동자 ID·TurnId로 결정해 같은 턴을 여러 번 조회해도 바뀌지 않는다. 전투의 명중 난수를 미리 소비하지 않는다.
- 후보는 모두 공통 요청 검증을 통과해야 한다. 스킬 기본 비용까지 포함해 감당 가능한 단계를 선택한다. 메모리가 부족하면 행동 번호를 낮춰 재시도하고, 전체 표가 불가능하면 낮은 투자 단계로 내려간다.
- 2기 구성은 생존 몬스터를 기준으로 평가한다. 동료가 죽으면 단독 표로 돌아간다. 서로 같은 속성도 문서의 전용 규칙을 적용한다.
- 방어 피해 배율은 상태로 저장해 피해·메모리 변경 중에도 유지하고 다음 행동/사망 시 해제한다. 기존 프로필 없는 몬스터는 이전 공통 점수 AI를 유지한다.

## 확정·가정·미제공

사용자 승인: 잔상에서 어느 쪽이든 최저 메모리 6번 구간이면 6번 우선. 각인이 2단계 투자도 불가능하면 무투자 공격.

추가 해석: 조건 백분율의 메모리 분모는 정의의 기본 메모리다. 각인 HP 비교는 표의 '자신 HP'를 사용한다(앞 문장의 '동료 HP'와 다름). 망각의 표에 없는 메모리 20% 미만/상대 15% 미만은 최하위 행을 사용하고 가용 비용 검증을 거친다. 약점 연쇄 3단계는 가장 높은 제공 표인 2단계를 적용한다. 잔상 첫 방어는 문서의 '1:1' 조건을 엄격히 적용하므로 동일 속성 2기에서도 첫 방어는 하지 않는다. 기본 스킬 비용조차 못 내는 각인은 방어 대신 Wait로 진행한다. HP·승패 계산은 기존 코어 정책을 유지한다.

보스는 이름만 있고 행동 규칙이 없다. 3기 전용 AI는 작성 예정으로 기재되어 있다. 현재 3기가 살아 있을 때는 단독 행동표를 사용하며, 2기가 남으면 동료 속성 조합표, 1기가 남으면 단독표로 전환한다. 잔상 첫 방어는 원래 참가 인원이 1기였던 전투에만 적용한다. 보스·3기 전용 규칙은 추후 기획에 맞춰 추가한다.

## 검증

기존 108개 + 새 37개 EditMode 테스트 **145개가 모두 통과**했다. 3종 박스 모두 데이터 연결, NavMesh 기반 9m 전투 배치·카메라 구도와 원위치 복구를 확인했다. 테스트에는 3종 × 4동료 구성 × 14자기 메모리 × 9상대 메모리의 유효 요청 검사(1,512개 조합), HP 행동 예시, 방어 실피해 30%, 첫 행동 기록, 고갈 시 무투자/대기, 동일 턴 결정성, 확률 분기가 포함된다. PlayMode는 실행하지 않았다.


속성 표시는 전투 상태 UI에서 `몬스터 이름 [속성]` 형식으로 이름 바로 뒤에 표시한다. 머리 위 속성 표시와 빌보드 처리는 제거했다. 기존 필드 감지 !/? 표시는 유지한다.
