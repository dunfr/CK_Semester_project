# 신규 FBX 맵 기반 튜토리얼 콘텐츠

- 브랜치: `feat/tutorial-demo-grayboxing`
- 플레이 씬: `Assets/CK_Semester_Project/Prototype/Scenes/TutorialGrayboxingDemo.unity`
- 맵 출처: `origin/feat/map-grayboxing-fuchsia`, `0275f98`의 `MapGrayboxingFuchsia.unity`와 `DummyModeling.fbx`.
- 구현 기준: 동선설계기획서(01)/(03), 컨텐츠기획서(01) v0.3 및 (02)~(04) v0.2.

## 맵 교체

기존 ProBuilder 지형을 신규 FBX로 대체했다. 원본 맵 씬은 브랜치에서 가져온 상태로 보관하며 실제 콘텐츠 연결과 문 개구부 수정은 TutorialGrayboxingDemo에서 수행한다. 기존 푸시아 FuchsiaUpdatedAnimated 프리팹, 리그·머티리얼·이동·달리기와 전투 Idle 설정, 기존 UI 에셋, 최신 battle-core AI 및 기본 스킬 강화 연결을 유지한다.

막힌 모듈은 문 위치에 해당하는 최소 단위만 비활성화해 튜토리얼 출입문, 엘리베이터 상/하층, 복도 a→c 카드키 문, 복도 b 입/출구, 홀 입구/내부 진입부와 상층 출구를 연결했다. 카드키 문과 엘리베이터 문에는 기존 개폐 컴포넌트를 사용한다. 복도 b 및 홀의 통과용 개구부는 열린 상태다. 배경용 문 전체를 이동시키지 않는다.

맵 높이는 상부 약 Y=0.3m, 하부 약 Y=-119.6m다. 기존 맵의 Y<2m 낙하 복귀 조건을 제거하고 -130m를 새 복귀 기준으로 사용한다. Debug 층 이동 버튼은 숨긴다.

## 플레이 흐름

1. 조작 잠금 → 첫 경비병이 콘솔까지 2.5초 이동 → 버튼 조작 안내 1.5초 → 캡슐 적색 표시 → 프레스 하강 도중 50% 지점에서 급정지 → 0.5초 정지 유지 → 조작 해제. 빨간 상승 막대는 제거했다.
2. 경비는 콘솔을 바라보며 정지한다. 좌클릭 선제 전투 및 기존 백어택 판정을 사용한다. 20초 동안 전투를 시작하지 않으면 뒤돌아 놀란 후 플레이어 위치를 추적한다.
3. 승리 후 콘솔 카메라 연출과 함께 카드키가 0.2초 상승한다. 자동 지급하지 않으며 콘솔에 접근해 좌클릭으로 획득한다. 카드 없이 문에 상호작용하면 안내와 0.5초 콘솔 카메라 유도를 제공한다.
4. 카드키로 출입문과 엘리베이터 문을 연다. 카 내부에서 패널을 좌클릭하면 7초 동안 카와 플레이어가 함께 하층으로 이동한다. 탑승 판정은 새 카의 BoxCollider 범위를 사용한다.
5. 복도 a의 적과 직접 마주치거나 복도 b의 벽/유리 구간을 이용한다. b의 소음 트리거 또는 a→c 카드키 문 개방 시 덕트 a 파손음은 한 번만 발생한다. A1은 제자리에서 소리 방향을 보고 A2/A3는 문이 열린 뒤 소음 지점을 확인하고 순찰로 돌아간다.
6. 덕트 위에서는 아래 경비의 시야 높이 범위를 벗어난다. 대각선 구간 대화를 자막으로 표시한다. 덕트 b를 밟으면 0.8초 하강, 충돌 해제, 실제 중력 낙하, 임시 파편/소리 파동과 붕괴음이 발생한다. C3~C6 네 경비는 낙하 지점을 조사한다.
7. 덕트를 타지 않는 지상 경로도 허용한다. 붕괴를 홀 입장의 필수 조건으로 사용하지 않는다. 홀에 진입해 두 경비의 순찰을 관찰하고 원본 경사로로 상층 출구까지 이동하면 완료된다.

전투 패배/맵 아래 낙하 시 체크포인트로 돌아가며 카드키·문·붕괴 상태는 유지한다. 첫 전투 이전 복귀는 경비 위치와 20초 대기를 다시 준비한다. 기존 요청대로 필드 상호작용은 E 대신 좌클릭, 달리기는 SHIFT/기존 버튼을 사용한다.

## 경비 배치와 NavMesh

첫 경비 1기, 복도 A1~A3 및 C1~C6 9기, 홀 순찰 2기: 총 12기다. 기존 MO00~MO08 정의를 보존하고 홀 경비는 기존 정의를 재사용한다. 전투의 능력치/행동 투자표/스킬 강화 규칙은 변경하지 않는다.

`Tutorial Grayboxing Navigation`의 기존 NavMeshSurface를 새 지형의 Physics Colliders 기준으로 다시 베이크했다. 캐릭터 자신의 충돌체는 베이크 동안 제외하여 시작 지점에 구멍이 생기지 않게 한다. 네 개의 가동 문은 NavMeshObstacle carving을 사용하고 베이크에서는 제외한다. 보행 연결로 이어지는 맵이므로 NavMeshLink는 추가하지 않았다.

`EnemyStateMachine`에 높이 차 시야 제한(0이면 기존 동작), 제자리 감시 옵션(기본 꺼짐), 기획 이벤트용 `ObserveNoise`/`InvestigatePosition` API를 추가했다. 기존 다른 씬의 기본 동작은 유지된다. 복도와 홀의 유리 구간은 시선을 통과시키며 물리 충돌은 유지한다.

## Inspector와 수정 경로

- `Tutorial Level Content / TutorialLevelFlow`: 경비 이동/놀람/20초 대기, 프레스 전체 하강 시간·거리·정지 비율·정지 유지 시간, 카드키 상승, 엘리베이터 시간, 관찰 시간, 붕괴 시간·소음 반경·낙하 복귀 높이 및 연결 참조.
- `Tutorial Level Content / TutorialSequenceEffects`: 캡슐 표시, 임시 효과 재질과 효과음 음량.
- 각 `TutorialFieldInteractable`: 종류, 거리(m), 문 시간(초), 문 이동량(m).
- 각 `EnemyStateMachine`: 기존 시야/청각/속도/순찰 지점에 추가된 최대 시야 높이 차(m)·제자리 감시 옵션.
- `TutorialMapRevisionIntegration.RebuildNavigation()`: 현재 씬 형상으로 NavMesh를 재베이크하고 씬을 저장한다.

`ReplaceCurrentMap()`은 교체 이전 데모를 한 번 변환하기 위한 도구이며 이미 교체된 씬에서는 중복 실행을 차단한다. 예전 `TutorialLevelIntegration`의 고정 좌표/ProBuilder 재생성 경로는 새 맵을 재생성하는 용도가 아니다.

## 임시 연출과 검증 범위

사용자 확인에 따라 전용 연출 에셋 없이 기존 메시 이동·회전, 단색 캡슐 표시·중간에 멈추는 프레스, 짧은 합성 효과음, 파편·파동, 자막으로 구현한다. 신규 FBX에 없는 복도 감시 데스크는 임시 큐브 프랍으로 보완했다. 버튼 조작·놀람의 최종 캐릭터 애니메이션, 음성/최종 대사, 정식 VFX·SFX는 아트 제작 시 교체할 부분이다. 기획서에 별도 연출 문서의 대화 내용이 없어 임시 문구를 사용한다.

플레이 시간 목표는 사람의 전체 플레이로 측정하지 않았다. UI 화면 비율 테스트는 기존 요청에 따라 실행하지 않는다. 자동 검증 결과는 작업 완료 시 아래에 기록한다.

### 최종 확인 결과 (2026-10-15)

- PlayMode 동선 테스트 5개, 전투 Idle·카메라 테스트 5개, 경비 AI 테스트 10개: 총 20개 통과, 실패 0개.
- 실제 첫 전투 승리 후 카드키 상승 및 수동 획득, 미보유 문 잠금·카메라 유도, 20초 경비 추적, 엘리베이터 탑승/동시 이동, 덕트 없이 진행·체크포인트 보존을 검증했다.
- CharacterController의 충돌 이동으로 신규 출입문→복도→엘리베이터→복도 b→덕트 경사로→붕괴/낙하→홀→원본 경사로→상층 출구까지 통과했다. 이동 구간 사이 텔레포트를 사용하지 않는다. 첫 문 위치에서 시작하도록 테스트 준비 위치만 배치한다.
- 두 복도 개구부, 홀 입구/내부 진입부, 상층 출구에서 캐릭터 크기의 캡슐 공간 검사 통과.
- 누락 스크립트/머티리얼 없음. 경비 12기와 전투 제어기 참조 12기, 푸시아 원본 리그의 SkinnedMeshRenderer 7개 및 FuchsiaLocomotion, BasicSkillEnhancement 연결 확인.
- UI 화면 비율 테스트 및 플레이어 빌드 검증은 실행하지 않았다.

- 실제 Play 모드에서 신규 맵 시작 화면과 기존 HUD를 확인했다. 최종 컴파일 및 Console 오류/경고 0건.

### 프레스 중간 정지 연출 변경

사용자 요청으로 붉은 내용물 상승 막대와 관련 런타임 코드를 제거했다. 캡슐 상부 프레스가 전체 하강의 50% 시점에서 급정지하고 0.5초 뒤 조작을 해제한다. 기본 전체 이동 거리 2m 중 실제 하강은 1m다. 거리·정지 비율·대기는 TutorialLevelFlow Inspector에서 조절한다. 실제 Play 모드에서 Y=4.25→3.25 정지, 빨간 막대 없음, 조작 복귀 및 Console 오류 0건을 확인했다. 시작/문 잠금 연계 테스트 1개 통과.
