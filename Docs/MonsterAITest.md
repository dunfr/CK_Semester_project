# 몬스터 AI 테스트 씬

## 실행

1. `Assets/CK_Semester_Project/Prototype/Scenes/MonsterAI_Test.unity`를 연다.
2. Unity에서 Play를 누른다.
3. 일반 / 플레이어 선제 / 몬스터 선제 진입을 선택하고 전투 조합을 누른다.
4. 기존 전투 UI로 스킬·메모리 투자·대상·방어를 선택한다.
5. 우측 상단 `전투 중단 / 초기화`로 전투 도중에도 다시 선택한다. HP·메모리·상태·적 활성 상태와 위치가 초기화된다.

## 구성

- 각인 A/B, 잔상 A/B, 망각 A/B 총 6기. 외형은 기존 회색 박스다.
- 단독 3종, 동일 속성 2기 3종, 서로 다른 속성 2기 3종의 총 9개 조합.
- A/B는 같은 속성 AI를 쓰는 별도 개체다. 문서에 없는 새 AI 유형을 추가하지 않았다.
- `Prototype/Data/MonsterAITest/`의 6개 정의 에셋은 각각 독립적이다. Play 전에 Inspector에서 HP·메모리 등 수치를 수정해 비교한다. TutorialDemo 원본 몬스터 데이터에는 영향을 주지 않는다.
- 선택된 적만 전투에 참여하고 나머지는 숨긴다. 자동 근접 진입은 이 씬에서 끈다.
- 일반 진입은 기본 순서, 플레이어 선제는 플레이어 추가 행동 1회, 몬스터 선제는 첫 번째 선택 몬스터의 추가 행동 1회다. 기존 충돌 메모리 보너스는 `Tutorial Battle`의 Inspector에서 조절한다.
- 전투 중 우클릭 드래그 카메라와 공격·피격 연출은 기존 전투 기능을 공유한다.

## 문서와 AI

제공된 `몬스터 AI 기획서 (1).pdf`는 저장된 `Docs/References/몬스터 AI 기획서.pdf`와 내용 및 파일 바이트가 같다. 기존 HP·메모리 조건표, 속성별 투자 단계, 1:1 잔상 첫 방어, 2기 조합표를 그대로 사용한다.

기존 승인 예외도 유지한다: 잔상 최저 메모리 구간은 6번 행동 우선, 각인은 2단계 투자가 불가능하면 무투자 공격(기본 소모도 부족하면 대기). 3기 전용 AI는 기획 확정 전이므로 이번 선택 메뉴는 1~2기로 구성한다.

## 공용 API 변경

- `TutorialBattleController.BeginBattle`에 선택적 `members` 인자를 추가했다. 생략하면 기존 근접 몬스터 선택을 유지한다. 지정 시 등록된 활성 몬스터 1~3기, 중복 없음, 첫 개체와 진입자 일치를 검사한다.
- `CancelBattle()`은 진행 중인 전투의 배치·UI·카메라를 복구한다. 테스트 패널이 이후 플레이어와 6기를 초기화한다.

## 검증

- Unity EditMode 전투 테스트 160개 통과.
- 9개 조합의 NavMesh 전투 배치 및 복귀 확인.
- 선택 화면 정지 렌더 확인.
- PlayMode 실행 및 실제 마우스 입력을 통한 전투 완주는 수행하지 않았다.
