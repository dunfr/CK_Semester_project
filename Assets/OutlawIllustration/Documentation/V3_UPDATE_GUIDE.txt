아웃로 일러스트 v3 업데이트

이번 그림 보완
- 바지 모양으로 잘려 있던 뒤 코트의 안감을 이어 그리고, 움직임 중 드러나는 범위까지 겹침 여유를 추가했습니다.
- 칼끝 뒤 배경에 남아 있던 고정된 분홍 잔상과, 칼 알파에 붙은 회색 배경 조각을 제거했습니다.
  칼을 휘게 만드는 수식 변경으로 처리한 것이 아니라 잔상 배경과 파츠 경계를 수정했습니다. 강체 동작 수식은 유지합니다.
- 하단 건물 배경을 선과 면이 이어진 새 배경 그림으로 교체했습니다. 이전의 퍼진 복원 경계와 원본 칼의 빛을 다시 합성하지 않습니다.

파일 교체
- 패키지 안의 기존 Assets/OutlawIllustration 경로와 v2 GUID를 유지합니다.
- 새 레이어에 필요한 파일은 별도의 새 GUID를 갖습니다.
- .unitypackage와 Assets ZIP은 같은 그림·코드·JSON을 담습니다. 둘 중 하나로 가져오면 됩니다.
- 프로젝트의 기존 Prefab과 Scene은 이 패키지가 직접 편집하지 않습니다.

새 UI 인스턴스 생성
1. .unitypackage를 재Import하거나 Assets ZIP의 OutlawIllustration 폴더를 프로젝트 Assets 아래에 덮어씁니다.
2. 기존 v2 일러스트가 아닌 부모 Canvas/Panel을 선택합니다.
3. Tools > Outlaw Illustration > Create UI Illustration를 실행합니다.
4. 생성된 v3 오브젝트의 텍스처·배경·강도를 확인합니다. 기존 v2 오브젝트는 비활성화해 겹치지 않게 합니다.
5. 필요하면 v3 오브젝트를 새 Prefab 또는 기존 Prefab의 교체본으로 저장합니다.

기존 v2 인스턴스 주의점
그림 파일의 GUID 유지와 UI 인스턴스의 레이어 목록 갱신은 다른 작업입니다.
새 레이어가 추가됐으면 기존 인스턴스에서 Rebuild Illustration만 실행해도 새 텍스처 binding이 생기지는 않습니다.
이번에는 위 메뉴를 통해 최신 rig와 PNG를 자동 연결한 v3 인스턴스를 생성하는 경로를 사용합니다.

확인할 곳
- 움직임 최대 구간에서 코트 안감과 바지 뒤쪽이 비지 않는지
- 칼끝과 주변 배경에 이전 칼의 잔상이 겹치지 않는지
- 하단 건물의 선과 면이 흐릿한 복원 경계 없이 이어지는지
- 사용하는 Canvas/Mask/해상도에서 잘림과 성능 문제가 없는지

실제 Unity Import/Play와 게임 빌드는 이 로컬 제작 검증에 포함되지 않았습니다.
