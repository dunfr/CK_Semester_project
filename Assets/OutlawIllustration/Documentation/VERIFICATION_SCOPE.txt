v3 배포 검증의 범위

배포 아카이브
각 파일의 Assets 경로, GUID, 파일 SHA256, meta SHA256과 ZIP CRC를 저장 후 재조회합니다.
기존 v2 파일과 같은 경로의 자산은 v2 GUID와 일치하는지 검사합니다.
이 검사는 .unitypackage의 내용과 구조에 대한 검사이며 Unity Editor 가져오기 결과와는 다릅니다.

렌더 입력
미리보기 영상이 사용한 rig SHA256 및 PNG별 SHA256을 최종 배포 PNG와 대조합니다.
같은 파일 이름의 그림이 바뀌었을 때 이전 영상을 새 결과로 오인하지 않도록 입력 버전을 구분합니다.

영상과 그림
MP4 전체 프레임의 디코딩을 검사하고, 선택한 움직임 시점의 시각 검토 결과를 별도로 기록합니다.
구체적인 시점·확대 위치·문제별 결과는 함께 제공되는 최종 작업 기록을 기준으로 합니다.

Unity
실제 Unity Editor Import, Play Mode, 목표 기기 FPS와 게임 빌드는 검증하지 않았습니다.
수학 비교나 최소 API 형상 스텁을 이용한 C# 구문 검사는 Unity 네이티브 컴파일·재생의 대체 근거가 아닙니다.
